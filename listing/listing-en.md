## Full description
WA Translate is an independent AI translator for WhatsApp Web. Pick the chats you want, and the extension translates incoming messages right under the original text and translates your replies before they are sent — so you can talk with anyone in any language.

★ HOW IT WORKS
• Incoming messages: the translation appears under each message, with a small badge showing which engine was used.
• Outgoing messages: press Enter, review the translation in a preview card, then send it (or edit it, or cancel). An "instant send" mode is also available.
• Translation keeps the meaning: AI engines get the recent conversation as context, so slang, tone and names are handled much better than with literal word-by-word translation.

★ ONLY IN THE CHATS YOU CHOOSE
Translation is off by default. Turn it on for a chat with one click on the translate button in the chat header (or in the extension popup). In every other chat the extension does nothing: no requests, no changes, Enter works as usual. You can also switch to "all chats" mode and exclude individual chats. Each chat can have its own reply language.

★ BRING YOUR OWN AI
Use the key you already have: Claude (Anthropic), GPT (OpenAI), Gemini (Google), Grok (xAI), OpenRouter or DeepL. Or use the free Google Translate engine without a key (literal translation). If your AI engine fails, an optional free Google fallback keeps the chat working.
• 25 languages, auto-detected source language.
• Casual or business style of your replies.
• Local usage counter with an approximate cost estimate.

★ PRIVACY
• No account, no developer server, no analytics, no ads.
• Your API keys and settings are stored only in your browser (chrome.storage.local).
• Message text is sent only to the translation engine YOU selected, using YOUR key, and only for chats where you turned translation on. With the Google engine / Google fallback, the text goes to Google Translate. See the privacy policy for details.
• The extension asks for access to a translation provider's server only when you select it.

★ GOOD TO KNOW
• Interface language of the extension: Russian.
• You need an API key from an AI provider (usually a few cents per thousand messages) unless you use the free Google engine.
• WhatsApp Web changes from time to time; if something stops working, enable "Diagnostics" in the popup and copy the report — it contains no message text.
